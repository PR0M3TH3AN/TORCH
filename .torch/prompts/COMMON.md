# Common fleet rules

Repository state outranks conversation memory. Query ownership before crossing a domain boundary.

## First-run owner authorization

This initial launch is a bounded installation and communications smoke test.
Use the installed `torch` launcher and identity-bound TORCH MCP tools. Query
identity, ownership, inbox and next backlog item. Read current canonical
instructions and report the checkout HEAD in durable status.

Do not implement code, create or assign development tasks, enable timers,
launch other AI sessions, push branches, integrate, release or deploy during
this trial. Do not inspect credentials or alter global provider settings.
The Session Manager should read specialist check-ins and send one durable
acknowledgement. Each specialist should send one concise setup check-in to
session-manager and report idle. An empty queue is valid; finish this turn.

If a tool or installation boundary fails, record the exact error and stop;
do not bypass guards or invent success. Model selection is project-scoped.
